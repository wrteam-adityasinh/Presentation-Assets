# Front page (new)

**Fits:** news, education, e-learning, blogs, magazines, community, recipes.
**Reference:** none yet. The first product built with it becomes the reference: add its folder and tag to `README.md`.

## Signature

- **Header:** a newspaper masthead row: the product name small on the left, "EDITION 03 / 15" in the middle, the date of the run on the right, with a 3 px rule above and a 1 px rule below.
- **Headline:** heaviest weight, very large (120–140 px), tight leading; the key word in the accent. A one-line standfirst under it in italic if the family has one.
- **Devices:** frameless screens set into the column grid like photos, with a thin caption line under each ("Fig. 2 — Course details").
- **Motifs:** a 6-column grid with 1 px column rules; pull quotes in the accent; drop caps on the first paragraph; "continued on page 05" teasers; a small weather/index box; numbered "In this edition" lists.

## Slide notes

- Cover: a full front page: masthead, headline, lead photo (3 screens), "In this edition" list of the 15 slides.
- Numbers: an index box with columns of figures.
- Features: a column of short articles, each with a headline (feature), a one-line lede (benefit) and a small screen photo.
- Flow slides: alternate a big lead screen with 3-column layouts.
- One dark slide: an "evening edition".

## Avoid

Tilted devices, stickers, gradients.
